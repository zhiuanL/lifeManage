# Final Design Decision Log

## Superseded
- Generic project-management mental model
- Configurable dashboard/card-wall homepage
- Dashboard widget layout as a primary persisted object
- Modules as isolated silos
- Hidden-only search entry

## Final
- Life Landscape as homepage mother metaphor
- Dual layer: Understanding Layer + Management Layer
- Domain Context Hub
- Domain many-to-many object association
- Capability Directory under More
- Weak-visible global search + progressive command mode
- Bottom Quick Capture composer
- Read-only detail side panel
- Inline full-detail editing
- Agenda-first calendar
- Dedicated Attention Center with expandable evidence
- Mixed visualization language
- Multi-theme: Warm Light / Deep Black / Blue Gray Dark / Warm Dark
- Add Domain directly from Life Landscape
