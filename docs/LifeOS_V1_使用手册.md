# LifeOS V1 使用手册

更新日期：2026-10-22  
适用版本：中文 V1 免安装调试候选版，`v1-20261022-no-console`。

## 1. 先了解 LifeOS

LifeOS 是单人、本地优先的生活管理工具。首页是“人生景观”，用于查看生活领域、
当前关注、方向、行动和复盘，而不是给人生打总分。

可以按这个顺序理解：

**人生景观 → 人生领域 → 目标、行动、习惯等能力 → 具体记录。**

领域是生活语境，不是文件夹。例如，一次跑步可以同时关联健康和关系，
但只保存一条行动，不需要在两个领域重复录入。

不必先填写全部模块。建议从几个领域、一个目标和少量行动开始，
日常维护控制在 5–10 分钟；允许断档，也不要求补齐所有日期。

## 2. 运行程序

### 2.1 选择正确版本

项目中的最新运行目录：

```text
portable\v1-20261022-no-console\
├─ test\LifeOS.exe
└─ user-data\LifeOS.exe
```

| 版本 | 用途 | 数据目录 |
| --- | --- | --- |
| `test\LifeOS.exe` | 推荐先查看效果、试用操作；已有自动化测试样例 | `%APPDATA%\com.lifeos.verification20261022` |
| `user-data\LifeOS.exe` | 使用原有生活空间；仅构建，未用正式数据启动测试 | `%APPDATA%\com.lifeos.app` |

双击相应的 `LifeOS.exe` 即可运行。免安装版不需要启动开发服务器，
也不需要 Node 或 pnpm；Windows 需要已有可用的 WebView2 运行环境。
最新版本不会附带控制台黑框。

**测试版和原数据候选版是两个独立空间，不自动同步。**
不要将测试版产生的样例误认为正式记录，也不要把测试备份恢复到正式空间。

### 2.2 使用原数据前

1. 关闭其他正在运行的 LifeOS。
2. 尽可能先用原版导出完整备份。
3. 退出原版后，另存整个 `%APPDATA%\com.lifeos.app` 目录，
   包括可能存在的 `lifeos.db-wal`、`lifeos.db-shm`。
4. 再运行 `user-data\LifeOS.exe`。

新版本可能向前迁移数据库。迁移后不要直接用旧版打开已升级的数据库。
如需回退，关闭所有 LifeOS 后恢复升级前的完整数据目录，不要操作运行中的数据库。

### 2.3 数据保存在哪里

桌面版将记录保存到所选空间的 `lifeos.db`。保存成功后，
关闭并重新打开程序，记录仍然存在。

免安装不代表数据存放在 EXE 旁边。移动 EXE 不会迁移数据，
删除 EXE 也不等同于删除数据库。

浏览器预览只用于查看效果，数据在内存中，刷新会清空，
不能替代桌面版长期保存，也不支持完整备份恢复。

## 3. 首次设置

从“设置”进入“生活空间初始化”，按需完成六步：

1. **人生领域**：保留、调整或添加自己需要的领域。
2. **目标模板**：选择适合自己的默认目标模板。
3. **复盘模板**：选择各周期默认模板。
4. **人生景观**：调整领域显示与位置。
5. **提醒规则**：设置关注提示的条件。
6. **启用模块**：只保留当前需要的能力。

可以选择“稍后继续”，以后再返回；不必一次配好全部内容。
如有未保存的编辑，先保存或撤销，再进入下一步。

全新空间预置事业、成长、健康、关系、财务五个推荐领域。
已有空间不会自动补入；可以在首页使用“添加推荐领域”，自行勾选需要的项。

## 4. 找到常用入口

| 入口 | 主要用途 |
| --- | --- |
| 人生景观 | 查看整体生活语境、领域、方向、注意事项和复盘入口 |
| 领域节点 | 查看该领域关联的目标、行动、指标等原始记录 |
| 目标与行动 | 管理目标、进度项和具体行动 |
| 复盘 | 日、周、月、季、年复盘 |
| 日历 | 按议程、周、月查看已有安排和记录 |
| 关注中心 | 查看提醒规则触发的提示及依据 |
| 更多 | 打开习惯、人物、分析、模板、备份等能力 |
| 顶部搜索 | 查找已有记录；`Ctrl+K` 可聚焦搜索 |
| 顶部 `+` | 打开快速记录，先收集想法 |

模块未显示时，先检查“更多”和“设置”中的启用模块配置。
停用模块只收起日常入口，不删除已有记录。

从领域进入某个能力时，页面通常带有领域筛选。
想查看全局记录，可以选择“全部领域”；不要因为筛选未清除而重复创建记录。

## 5. 人生景观与领域

### 5.1 记录当下生活语境

首页可以按需填写整体生活状态、当前阶段、当前重心和生活张力。
这些内容是自己的描述，不是系统评分；不想填写可以留空。

### 5.2 添加和维护领域

1. 在人生景观选择“添加领域”。
2. 填写名称，并按需补充描述、长期期待、颜色或图形。
3. 保存后点击领域节点，进入该领域上下文。
4. 从领域进入目标、复盘、指标等能力，查看或建立关联记录。

不再重点维护的领域可以暂停或归档，保留历史关系。
仅希望首页更简洁时，可以隐藏领域，不必归档。

领域满意度可以选择关联已有指标，也可以不评分。
系统不会自动把普通指标当作满意度，也不会生成全人生总分。

## 6. 目标与行动

### 6.1 创建目标

1. 进入“目标与行动”，使用新建目标入口。
2. 填写标题，选择适合的模板或类型。
3. 按需关联领域、上级目标、周期、优先级和长期方向。
4. 保存后查看目标详情。

创建年度目标时需要关联长期方向；可以先到“人生导航”记录方向。
目标可以关联多个领域，不要为每个领域复制同一个目标。

点击目标名称会打开只读预览；需要修改时进入完整详情，
通过相应区块的编辑入口保存，不是在只读预览里直接填写。

### 6.2 使用进度

根据目标性质，可以使用关键结果、里程碑、量化结果、探索节点，
或关联习惯的周期统计。需要时展开“进度设置”，调整当前值、目标值和权重。

进度来源不足时可能没有百分比，这是缺少可用事实，不是程序丢失数据。
探索型目标默认不显示百分比；无需为了显示进度而补造数值。
列表筛选只影响显示，不改变完整事实的进度计算。

### 6.3 创建和完成行动

1. 创建一条可以实际执行的行动，例如“周三晚走路 20 分钟”。
2. 按需关联目标和领域，填写计划日期或截止日期。
3. 执行后标记完成。
4. 需要时再补充结果、投入分钟、收获、问题和后续调整。

快捷完成不要求写完整反馈。投入 `0` 分钟与未填写含义不同，请按事实记录。
调整安排时如页面要求原因，记录实际调整原因即可。

### 6.4 查看结束的记录

目标支持候选、进行中、暂停、已完成、放弃、归档六种状态。
暂停或放弃时记录原因；历史仍保留。

默认列表会收起部分已结束目标和已完成行动。
找不到记录时，切换“全部记录”或调整状态筛选，也可以使用全局搜索。

## 7. 快速记录与收集箱

1. 点击顶部 `+`。
2. 输入想到的事情，先保存到收集箱，不必马上分类。
3. 稍后从“更多”进入“收集箱”。
4. 阅读建议，确认后转为目标、行动、复盘、问题、决策、人物或事件。

系统建议只是辅助，不会替你自动确认分类。
复杂内容可以先保留，等周复盘时再整理。`Escape` 可关闭快速记录窗口。

## 8. 指标与习惯

### 8.1 每日状态与指标

从“每日状态与指标”，或领域中的指标入口，创建指标：

1. 设置名称、单位和需要关联的领域。
2. 选择真实日期，填写实际数值。
3. 按需补充备注，保存。
4. 录错时更正原记录，不要用另一条重复记录抵消错误。

例如：睡眠时长，单位“小时”；步行距离，单位“公里”。
数值 `0` 是有效记录，留空则不是零。没有记录的日期不会自动补齐。
趋势反映已记录数据，数值下降不一定代表生活变差。

### 8.2 习惯

1. 从“更多”进入“习惯”。
2. 创建习惯，设置每周期望频率并关联领域。
3. 完成时打卡，需要时补记或撤销错误打卡。
4. 展开“周期统计”查看已有完整周的数据。

统计基于已记录事实；没有足够记录时显示“暂无”或未知。
不要求每天打卡，不必为追求连续记录补造事实。

## 9. 日历

日历默认使用议程，也可以切换周视图或月视图，
按领域和记录类型筛选。

日历汇总已有行动安排、目标截止、习惯安排与实际记录、复盘及事件。
点击对应记录返回来源，修改行动时修改的也是同一条行动。

需要改变安排时回到原行动编辑，不要另外创建一条“日历副本”。

## 10. 复盘

### 10.1 创建复盘

1. 进入“复盘”，选择日、周、月、季或年周期。
2. 核对日期与关联领域，选择模板。
3. 在分区中记录事实、感受、问题和下一步。
4. 尚未写完就保存草稿；整理完成后标记已完成。

首页没有本周复盘时，可以使用“开始本周复盘”入口。
月、季、年复盘还可以选择叙事模式。

### 10.2 使用事实汇总

周、月、季、年草稿可以汇总已有行动、下级复盘、指标、问题和当前目标等事实。
这些内容只是草稿材料，需要自己核对、补充或删除。

已保存复盘不会自动反复改写；需要时显式使用“汇总事实”。
手工填写和主动清空的内容受到保护。缺少日常记录仍可以正常复盘。
当前目标或能力快照不等于历史增长量，不应据此推断全年变化。

可以显式关联目标和问题，便于后续追踪。
修改模板不会改写旧复盘，旧复盘保留保存时的模板快照。

## 11. 问题、决策与个人记录

| 能力 | 建议记录的内容 |
| --- | --- |
| 人生导航 | 使命、价值观、愿景、长期方向、个人原则；可以留空 |
| 身份角色 | 当前承担的角色及关联信息；从设置相关入口进入 |
| 问题 | 反复出现的现象、首次发现、原因假设、尝试和跟进 |
| 决策 | 选项、约束、风险、最终选择和理由；重大决策再补完整背景 |
| 人物 | 已确认的关系信息、联系状态、生日和重要日期 |
| 重要事件与时间线 | 真实事件及关联人物、目标、领域；查看已有历史节点 |
| 能力成长 | 当前与期望水平、学习路径、实践和复盘 |
| 资源总览 | 目标或决策所需资源、已具备和待补齐项 |
| 系统成效评估 | 月度或季度主观回看系统是否真正帮助自己 |

资源总览引用已有信息，不是财务余额、库存或文件管理系统。
没有资源记录不代表充足，也不代表不足。

## 12. 关注中心与分析

关注中心显示规则触发的提示，例如目标日期、行动静止、反复问题、
多次改期或指标连续下降。展开依据，再决定是否处理。

提醒不是系统对你的评价；可以在设置中调整阈值。

分析页查看排期、实际完成、改期依据和指标趋势，也支持多领域对比。
各指标保留自己的单位，共享记录不应重复相加。
旧行动缺少历史依据时，不会被强行计入到期完成率。

## 13. 搜索、模板与设置

**搜索**：点击顶部搜索或按 `Ctrl+K`，输入关键词，
必要时按类型、日期、状态、领域缩小范围。

**模板**：从“模板中心”复制或创建模板，修改初始字段和顺序。
使用模板会带入新建表单，仍需确认保存；修改模板不修改已保存对象。

**设置**：选择主题，调整领域显示、模块启用、提醒规则和常用入口。
模块停用不删除数据；高级设置只在需要时展开。

**版本历史**：从支持历史的记录入口查看保存前版本。
历史用于追溯，不要把只读历史预览当作一键恢复按钮。

## 14. 上下文导出与隐私

LifeOS 不直接调用 AI 接口，不自动把记录上传到云端。
需要外部分析时，自己决定导出哪些信息。

1. 从“更多”进入“上下文导出”。
2. 选择分析场景或模板。
3. 设置时间、领域、目标、记录类型和最高隐私等级。
4. 调整包含的字段与顺序。
5. 阅读预览，确认没有带出不希望分享的内容。
6. 按页面要求确认后，选择 Markdown、纯文本或 JSON 导出。

改变范围或隐私条件后，需要重新确认。
高度敏感记录不纳入上下文导出。若缺少预期内容，
先检查日期、领域、直接关联和隐私条件，不要盲目放开所有隐私。

**上下文导出不是完整备份。** 它经过筛选，不能用来完整恢复生活空间。
将文件交给外部工具后，信息的处理不再由 LifeOS 控制，请自行判断分享范围。

## 15. 备份与恢复

### 15.1 创建备份

1. 在桌面版从“更多”进入“备份与恢复”。
2. 点击“下载 JSON 备份”。
3. 确认文件已经保存，将其放在安全位置。
4. 建议升级前、批量调整前以及定期维护时备份，保留多个日期版本。

完整备份包含全部隐私等级、关联、历史和模板，**文件未加密**。
当前备份版本为 52，可恢复 LifeOS 15–52 版本的受支持备份，
不是任意 JSON，也不是其他软件的通用导入文件。

### 15.2 从备份恢复

**恢复会替换当前空间的数据，不是追加合并。**

1. 先核对当前是测试空间还是正式空间。
2. 为当前空间另存一份完整备份。
3. 选择有效的 LifeOS JSON 备份文件。
4. 阅读预检结果，确认文件及替换范围。
5. 勾选确认，再点击“确认恢复”。
6. 等待结果，记录页面显示的恢复前安全快照路径。
7. 按提示重新载入；如重载未完成，关闭并重新打开应用后核对记录。

恢复前会自动保存安全快照，通常位于所选应用配置目录的 `backups` 下。
约束或关联检查失败时恢复会回滚；如提示恢复已完成、仅重载失败，
不要再次恢复，只重新载入。

备份未加密，V1 也不提供数据库加密或应用锁。
本地保存不等于他人无法读取，应保护电脑账户与备份文件。

## 16. 一条完整使用示例

以“增加日常活动”为例：

1. 保留或创建“健康”领域。
2. 创建阶段目标“建立稳定的步行安排”，关联健康。
3. 新建行动“周三晚走路 20 分钟”，关联该目标。
4. 如果需要周期打卡，另外创建“每周步行三次”的习惯，
   不要把习惯和一次性行动混为同一种记录。
5. 执行后完成行动，按需打卡；需要测量时记录步行距离指标。
6. 想法和困难先通过顶部 `+` 存到收集箱。
7. 周末创建周复盘，核对已有事实，写下阻碍与下周调整。
8. 下周调整原行动或创建新的实际行动，定期导出完整备份。

不一定要配置百分比或录入每日指标。先让记录帮助真实生活，
再决定哪些高级能力值得长期使用。

## 17. 常见问题

| 现象 | 先检查什么 |
| --- | --- |
| 启动仍有黑框 | 是否还在运行旧 `v1-20261022` EXE 或旧快捷方式；改用 `v1-20261022-no-console` |
| 看见“统一测试”等样例 | 当前可能是隔离测试空间，这是预置测试记录，不是正式数据丢失 |
| 记录突然看不到 | 领域、日期、状态筛选是否限制了显示；切到全部记录或搜索 |
| 找不到某个模块 | “更多”中是否有入口；设置中是否停用了该模块 |
| 进度或统计显示暂无 | 是否有足够的可用事实、完整周记录或进度配置；不要补造数据 |
| 保存失败 | 阅读中文提示，保留草稿，按页面提供的重试或撤销操作；不要连续重复提交 |
| 无法打开本地生活空间 | 记录错误提示，退出后先备份所选数据目录；不要删库或修改应用标识 |
| 刷新后记录没了 | 是否用的是浏览器内存预览，而不是桌面 EXE |
| 恢复提示完成但未刷新 | 重新载入或关闭重开，不要重复执行恢复 |
| 导出缺少内容 | 检查范围、隐私等级、字段选择和实际关联 |
| 提示端口 1420 被占用 | 这是开发服务器问题；免安装 EXE 不需要启动开发服务器 |

不要为“重新开始”直接删除数据库。迁移不兼容或异常时，
先保留完整数据和错误信息，再处理。

## 18. 当前版本边界

本版为未签名、未优化的调试候选，不是安装包。
